# Root Git compatibility for admitted canonical repositories

During the first actual task preparation, fixed-identity Hermes stdio successfully retained the proposal, but a root Git probe of the operator-owned canonical robot mount failed with exit128 (dubious ownership). This exposed a real boundary mismatch not covered by earlier synthetic acceptance: those canonical fixture repositories were root-owned.

The Git helper now supplies safe.directory for only the exact resolved repository in that command. It keeps global/system Git configuration disabled and turns optional locks off for read-only queries. There is no wildcard, persistent trust setting or chown. This trusts the admitted repository and its operator-managed Git configuration; the registry/caller is part of the trusted operator boundary. This helper is not an arbitrary model-accessible root Git API.

Git local-clone ownership checks still rejected the source when the outer clone command had exact safe.directory entries. Worker-clone and review-commit preparation therefore first create a root-private temporary Git bundle from the admitted canonical repository with exact command trust, clone that same-owner bundle, remove its remote, and clean up the temporary files. Existing captured-commit verification and private worker ownership remain unchanged. This is local Git transport compatibility, not a new task lifecycle service. No global configuration, source ownership, networking or sandbox privilege changes are required.

Validation distinguishes environments: root against the existing read-only Hermes canonical mount reproduced the ownership error; a private temporary bundle/clone probe passed and cleaned up; the exact patched activity helper passed a root read-only query. These are container-root compatibility probes, not host-root acceptance, a native coding run, or provider authentication. Source tests cover actual local cloning, selected baselines, temporary cleanup and exact trust/options. Production source installation and host-root task capture remain separate gates.
